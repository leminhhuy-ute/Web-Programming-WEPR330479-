# Tài liệu cũ của module quản trị

Nội dung module quản trị đã được tích hợp vào ứng dụng Spring Boot chung. Tài liệu chuẩn, lệnh chạy H2/MySQL và tài khoản demo hiện được duy trì tại [README.md](README.md).

Không sử dụng lại hướng dẫn WAR/Tomcat rời trước đây: dự án hiện đóng gói executable JAR và chạy bằng Tomcat nhúng.
